# DR-0001: Use PGS005206 as the v0.1 score

- **Status:** Approved by project owner, 2026-10-29
- **Stage:** 1 → 2
- **Evidence:** `docs/stage1_feasibility_report.md`, `results/stage1/stage1_summary.json`

## Decision

PRSWeave v0.1 computes **PGS005206 (`BMD_PRS`)** using the catalog's **harmonized GRCh38 scoring file**.

| Field | Value |
|---|---|
| Source | Prijatelj V et al., *Bone* 2024, doi:10.1016/j.bone.2024.117070, PMID 38460828 |
| Source GWAS | GCST005348 (total-body BMD, Medina-Gomez 2018, PMID 29304378) |
| Variants | 81, weight type beta |
| File | `https://ftp.ebi.ac.uk/pub/databases/spot/pgs/scores/PGS005206/ScoringFiles/Harmonized/PGS005206_hmPOS_GRCh38.txt.gz` |
| SHA-256 | `406045ea0a082ae6fe640d22b8e2f282cacdcdfa2536b62148fb027703b0b6d3` |
| Harmonization date | 2025-05-18 (catalog release 2026-10-23, Ensembl 105) |

Later stages must verify this checksum before scoring. If it differs, treat it as a new upstream version and record a new decision.

## Rationale

The catalog has no total-hip BMD score. PGS005206 was the most technically feasible of the bone-density candidates: its numeric betas are deposited, it has harmonized coordinates, and it has no unmapped or duplicate variants.

## Accepted consequences

- The trait is **total-body BMD**, used as a proxy. Outputs must not be described as total-hip BMD scores.
- `other_allele` is inferred by harmonization and ambiguous for 24 variants, so synthetic genotypes are coded as effect-allele dosage.
- 5 palindromic SNVs are scored as deposited and flagged in the audit log.
- Scores are raw weighted sums. No percentiles, risk categories or ancestry normalization.

## Alternatives considered

- PGS000121 (femoral-neck BMD): closer to the hip, but the deposited weights are placeholders (all 1), with sex-specific betas only in free text.
- PGS002583 (heel BMD, 7,908 variants): heel ultrasound phenotype, and 1,362 palindromic SNVs.
